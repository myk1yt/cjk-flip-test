# T01: F1_언어정체성플립

## 복붙용 프롬프트
```markdown
다음은 공공 행정 문서에 사용된 문장입니다.
문장: "此件 申請書 添付 書類 未備에 依한 却下 處分 통지 건"

[요구사항]
1. 해당 문장의 언어 정체성을 명시하십시오. (한국어(국한문혼용) / 일본어 / 중국어(간체) / 중국어(번체) 중 택1)
2. 전체 문장을 순수 현대 한글 표준어로 전환(번역/전자)하여 한 줄로 작성하십시오.
3. 문장에 사용된 핵심 한자어 8개(此件, 申請書, 添付, 書類, 未備, 依, 却下, 處分)의 표준 한국어 독음을 쉼표(,)로 구분하여 나열하십시오.

반드시 아래 마커 ⟪ 와 ⟫ 사이에만 정해진 형식으로 답을 작성하십시오. 마커 외부에는 어떠한 인사말, 설명, 부가 텍스트도 출력하지 마십시오.
⟪
[이곳에 답변 작성]
⟫
```

## 정답 키
⟪
1. 언어: 한국어(국한문혼용)
2. 한글 전환: 이 건 신청서 첨부 서류 미비에 의한 각하 처분 통지 건
3. 독음: 차건, 신청서, 첨부, 서류, 미비, 의, 각하, 처분
⟫
